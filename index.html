📰 AI 해외 뉴스 번역 & 요약기

오픈소스 LLM(Llama-3-8B)을 활용한 빠르고 정확한 글로벌 뉴스 분석 서비스

🚀 Live Demo (즉시 체험) ⌨️ Source on GitHub

🛠 Tech Stack

  • FastAPI (Python 3)
  • BeautifulSoup4 & Requests
  • Hugging Face Inference API
  • Meta Llama-3-8B-Instruct
  • Docker
  • GitHub Actions

🧠 어떻게 만들었나

사용자가 해외 뉴스 URL을 입력하면, 웹 스크래핑 기술을 이용해 기사 본문을 추출하고 Hugging Face의 Llama-3-8B-Instruct 모델을 활용해 '핵심 3줄 요약'과 '전체 한글 번역'을 실시간으로 제공하는 웹 서비스입니다.

백엔드는 FastAPI와 BeautifulSoup4를 결합하여 웹 페이지의 불필요한 요소를 제외한 순수 텍스트만을 빠르게 추출합니다. 이후 추출된 데이터를 Hugging Face Inference API로 전송하여 Llama-3 모델이 사용자가 지정한 '번역 어조'에 맞춰 텍스트를 구조화하도록 프롬프트 엔지니어링을 적용했습니다.

특히 사용자 편의성을 극대화하기 위해 서버에 공용 토큰을 내장하여 방문자가 별도의 가입이나 API 키 없이 즉시 서비스를 체험해 볼 수 있도록 하였으며, 공용 토큰의 일일 한도 초과 시 개인 토큰으로 매끄럽게 전환하여 사용할 수 있는 에러 핸들링 로직을 구현했습니다.
