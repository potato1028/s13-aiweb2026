🚀 [AI 유튜브 자막 생성기]

[Gemini 2.5 Flash를 활용한 실시간 맞춤형 번역 자막 오버레이 서비스]

▶ Live Demo ⌨ Source on GitHub

🛠 Tech Stack

  • FastAPI (Python 3)
  • Gemini 2.5 Flash API
  • yt-dlp & YouTube IFrame API
  • Docker
  • Hugging Face Spaces
  • GitHub Actions

🧠 어떻게 만들었나

사용자가 입력한 유튜브 영상의 오디오를 추출하여 AI로 도메인 맞춤형 한국어 자막을 생성하고, 영상 재생 시간에 맞춰 실시간으로 화면에 띄워주는 서비스입니다. 백엔드는 FastAPI와 yt-dlp를 활용해 오디오를 처리한 뒤 Gemini 2.5 Flash API에 사용자가 지정한 '번역 테마' 프롬프트를 동적으로 주입하여 문맥에 맞는 자막을 생성하며, 프론트엔드는 YouTube IFrame API와 Document PiP API를 사용해 영상과 자막을 실시간으로 동기화하고 미니 플레이어 화면을 제공합니다. 사용자가 Gemini API Key, 유튜브 영상 URL, 그리고 원하는 번역 테마(예: 2D 플랫포머 게임 개발, IT 기기 리뷰 등)를 입력하면, 자막이 실시간으로 오버레이되는 유튜브 영상 화면과 함께 PIP 모드 기능이 출력됩니다.
