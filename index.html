📰 프리미엄 AI 해외 뉴스 번역 & 요약기

OpenAI, Gemini, Llama 다중 폴백 시스템과 5가지 편의 기능을 탑재한 고가용성 웹 서비스

🚀 Live Demo (즉시 체험) ⌨️ Source on GitHub

🛠 Tech Stack

  • FastAPI (Python 3)
  • BeautifulSoup4
  • OpenAI API (GPT-4o-mini)
  • Google GenAI (Gemini-2.5)
  • Hugging Face (Llama-3.1)
  • html2canvas (Image Export)

🧠 어떻게 만들었나

단순한 번역기를 넘어, 실제 서비스 환경에서도 안정적으로 동작하는 고가용성(High Availability) 아키텍처와 사용자 친화적인 UI를 결합한 프리미엄 뉴스 요약 서비스입니다.

1. 3중 AI 폭포수(Waterfall) 폴백 시스템

서버 과부하로 인해 단일 AI 모델이 응답하지 못할 경우를 대비해 백엔드에 다중 우회 로직을 구현했습니다. OpenAI (GPT-4o-mini)가 실패하면 즉시 Google Gemini (2.5-Flash)로, 그것마저 실패하면 Hugging Face (Llama-3.1-8B)로 요청을 넘겨 사용자는 에러를 눈치채지 못하고 무조건 결과물을 받을 수 있도록 설계했습니다.

2. 프롬프트 엔지니어링을 통한 핵심 키워드 추출

단순 정규식을 통한 무의미한 단어 빈도수 추출 방식을 버리고, AI 프롬프트에 '해시태그 생성 지침'을 주입했습니다. 기사의 문맥과 고유명사를 완벽히 이해한 AI가 뽑아낸 태그를 서버가 분리하여 프론트엔드에 깔끔한 뱃지 형태로 전달합니다.

3. 5가지 프론트엔드 프리미엄 기능

순수 HTML/JS를 활용해 부가적인 서버 부하 없이 클라이언트 단에서 ① 다크모드 토글, ② Web Speech API를 활용한 뉴스 음성 읽기(TTS), ③ html2canvas를 활용한 요약본 이미지 저장, ④ LocalStorage를 이용한 나만의 스크랩북 기능을 구현하여 실제 상용 서비스 수준의 사용성을 확보했습니다.
